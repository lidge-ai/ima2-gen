# 1. Official xAI documentation

### Images

- [doc-cited] `grok-imagine-image-2.0` accepts `quality: low | medium | auto`. The guide says **“Auto currently uses `low` for image generation and `medium` for image editing.”** It also documents `n` from 1–10, `url` or `b64_json` output, and asynchronous `deferred` requests. [Image generation](https://docs.x.ai/developers/model-capabilities/images/generation.md)
- [doc-cited] Image resolutions in that guide are `1k` and `2k`; supported aspect ratios include `21:9` and `5:2`. [Image generation](https://docs.x.ai/developers/model-capabilities/images/generation.md)
- [doc-cited] `grok-imagine-image-quality` was retired on November 2, 2026, but **“The slug continues to resolve”**: it redirects to image 2.0 at `low`. The older `-pro` slug follows that redirect; base `grok-imagine-image` is unaffected. [Retirement migration guide](https://docs.x.ai/developers/migration/imagine-image-quality-nov-2.md)
- [doc-cited] Image editing permits **“up to five source images”**. [Multi-image editing](https://docs.x.ai/developers/model-capabilities/images/multi-image-editing.md)
- [doc-cited] Starting prices are listed as $0.04/image for image 2.0 and $0.02/image for the base image model. Actual image 2.0 price depends on quality, resolution and edit inputs. [Pricing](https://docs.x.ai/developers/pricing.md), [retirement migration guide](https://docs.x.ai/developers/migration/imagine-image-quality-nov-2.md)
- **Documentation conflict:** the general [model catalog reference](https://docs.x.ai/developers/rest-api-reference/inference/models.md) describes a medium default and lists pricing tiers including `high` and `1.5k`. The generation-specific guide instead documents `low | medium | auto`, `1k | 2k`, and the operation-dependent auto behavior above. Do not send `high` or `1.5k` based solely on the catalog pricing schema.

### Video

- [doc-cited] `grok-imagine-video-1.5-lite` supports text-to-video and image-to-video, 1–15 seconds, and upscaled 1080p. It does **not** support reference images; the overview recommends full 1.5 when references, voice references, pinned frames, or native 1080p are needed. [Video overview](https://docs.x.ai/developers/model-capabilities/video/overview.md)
- [doc-cited] Full 1.5 has native 1080p for text-to-video and image-to-video. Reference-to-video is capped at 720p. Lite’s listed price is **“$0.020 per second”**; full 1.5 is listed at $0.080/sec and base at $0.050/sec. [Video generation](https://docs.x.ai/developers/model-capabilities/video/generation.md), [Lite model card](https://docs.x.ai/developers/models/grok-imagine-video-1.5-lite.md), [pricing](https://docs.x.ai/developers/pricing.md)
- [doc-cited] Full 1.5 accepts up to 14 reference images and three preset voice references; base is documented at seven images. `image` can pin the first frame alongside references, `last_frame` pins the end, and up to four `keyframes` pin interior images. Keyframe timestamps must be strictly inside the duration and occupy distinct 1/3-second slots. [Reference-to-video](https://docs.x.ai/developers/model-capabilities/video/reference-to-video.md)
- [doc-cited] A reference voice **alone** is a valid reference-to-video input; a prompt is optional when an image or frame pin is present. [Reference-to-video](https://docs.x.ai/developers/model-capabilities/video/reference-to-video.md), [video generation](https://docs.x.ai/developers/model-capabilities/video/generation.md)
- [doc-cited] Video generation returns a request ID; clients poll `GET /v1/videos/{request_id}`. Editing uses `/v1/videos/edits` and inherits input dimensions up to 720p; extension uses `/v1/videos/extensions`, with the added segment documented as **2–10 seconds**, default six. [Video generation](https://docs.x.ai/developers/model-capabilities/video/generation.md), [editing](https://docs.x.ai/developers/model-capabilities/video/editing.md), [extension](https://docs.x.ai/developers/model-capabilities/video/extension.md)
- The extension guide contains an example using 1.5, whereas this repository records older 1.5 rejection evidence. **[inferred]** That example warrants a contract check; it does not by itself establish that changing the repository’s 1.5 edit/extend gate is safe.

### Voice, STT and TTS

- [doc-cited] `grok-voice-latest` currently aliases `grok-voice-3.0`; 2.0 is deprecated. Speech-to-speech `reasoning.effort` accepts `high` or `none`, default `high`. The API uses `wss://api.x.ai/v1/realtime`; one compatibility difference is cumulative `conversation.item.input_audio_transcription.updated`. [Speech-to-speech](https://docs.x.ai/developers/model-capabilities/audio/speech-to-speech.md), [release notes](https://docs.x.ai/developers/release-notes.md)
- [doc-cited] STT defaults to `grok-voice-transcribe-2.0`. The release notes say 1.0 reached end of life on October 2 but **“requests to that slug are routed”** to 2.0; the starting claim that requests simply shut down is therefore too strong. REST and streaming both expose `filler_words` and `vad_threshold`; streaming additionally has `smart_turn_timeout` of 1–5000 ms when Smart Turn is enabled. [Speech-to-text](https://docs.x.ai/developers/model-capabilities/audio/speech-to-text.md), [release notes](https://docs.x.ai/developers/release-notes.md)
- [doc-cited] TTS supports `optimize_streaming_latency: 0 | 1 | 2`; `0` is the default. The guide also documents `speed`, normalization, character timestamps and pronunciation replacement. `GET /v1/tts/voices` lists voices. The same roster is used by speech-to-speech and video preset voices. [Text-to-speech](https://docs.x.ai/developers/model-capabilities/audio/text-to-speech.md), [speech-to-speech](https://docs.x.ai/developers/model-capabilities/audio/speech-to-speech.md), [reference-to-video](https://docs.x.ai/developers/model-capabilities/video/reference-to-video.md)
- The Aside-rendered TTS text did not expose the complete voice table, so **28 built-in voices is not independently verified** in this investigation. A read-only roster request is the appropriate account-specific check.
