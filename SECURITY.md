# Security Policy

## Supported versions

Only the npm `latest` release of `ima2-gen` is supported.
Preview tags and older patch lines are best-effort.

## Reporting a vulnerability

Do **not** open a public issue for a security report.

Use GitHub Security Advisories on this repository:

https://github.com/lidge-ai/ima2-gen/security/advisories/new

If that form is not enabled yet, email the maintainer listed in
[README.md](README.md) and say so. Do not attach cookies, OAuth tokens,
API keys, raw upstream payloads, or generated base64.

## Response

There is one maintainer. There is no promised SLA.
Reports are handled best-effort. Do not expect a 48-hour reply.
