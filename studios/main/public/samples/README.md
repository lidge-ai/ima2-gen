# Sample media

Made for ima2 on 2026-11-26. The stills were generated from text prompts with an
image model; the clips are camera moves (push, pan, crane, sway, zoom) rendered
from those stills with ffmpeg. No third-party photos, footage or brand assets.

The *-poster.jpg files are the first frames of the clips (ffmpeg, 640 px wide), shown before playback and when motion is reduced.
